Task Tracker is a single-page task tracker that runs in the browser. It needs no server, no framework, and no build step. The whole app is in one file, index.html.

You can add tasks with a title, an optional description, a priority, and an optional deadline. Each task can have subtasks. A task's progress is based on its subtasks when it has any, and you can set it manually when it has none. Tasks can be filtered, searched, and sorted. Overdue tasks are highlighted. There are six color themes, and the tasks and theme are saved in the browser.

Limitations: it works on one browser and one device only, with no syncing, no reminders, and only one level of subtasks.
